## 审题 checklist(转正前人工确认)

- [ ] issue 描述与实际缺陷一致,无泄底(不直接点名根因文件);
- [ ] 修复方案唯一且自然,无"另一种等价修法被回归集误杀"的风险;
- [ ] 难度标定为 hard 恰当(预期真实模型 ≥2 轮或多轮失败);
- [ ] `allowed_paths` 覆盖所有自然修法可能触碰的文件。
