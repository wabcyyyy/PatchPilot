> 本索引规定**每类问题只由一个文件回答**,其余文件引用它而不是重述它。

## 3. 维护约定

1. **不在第二处重述事实**。要引状态机/门禁/判定规则,写"见企划书 X 节",不要抄一份。
2. **生成产物只由命令产生**。改了代码里的判定或聚合口径后重跑命令,不手改报告正文;需要说明口径时在文件头加补注。
3. **一次性文档用完即归档**:`docs/archive/` 下按 `YYYY-MM-DD-主题.md` 命名,并在文首写归档状态与"与今不符处"。
4. **状态类问题的权威顺序**:git 提交记录 > `audit-2026-09-20.md` > 计划书。计划书复选框不作为状态依据。
5. 已退役的早期初稿《PatchPilot项目初步企划书与学习建议》于 2026-09-19 删除,历史见 git。
