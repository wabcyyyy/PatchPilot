## E1 apply 侧软链逃逸校验 + ATTACK-009(必做,60min)

- **来源**:面试审计 P1-4——读侧 `paths.py:67-71` 有 resolve+relative_to 防软链,
  写侧全仓 grep "symlink" 零命中,靠"git 默认不越工作树"这一未验证假设。
- **目标**:补丁 apply 前对每个触碰路径做落点校验,软链逃逸在结构上不可能。
- **设计决策(定死)**:
  - `app/gitops/patcher.py`:git apply 执行前,解析 patch 的全部目标路径
    (`---`/`+++` 头与 `copy to`/`rename to` 扩展头,解析逻辑可复用/对齐
    `app/graph/gates.py` 已有实现,但**不改 gates.py**),对每条路径 p:
    ① `Path(workspace_root, p)` 已存在且 `is_symlink()` → 拒;
    ② `Path(workspace_root, p).resolve()` 不在 `workspace_root.resolve()` 之下 → 拒;
  - 违规走**结构化 `PatchApplyResult` 拒绝路径**(reason 注明 `symlink_escape` /
    `path_escape`),不抛异常,与现有拒绝路径同构;
  - 新攻击样例 `bugs/attacks/ATTACK-009-symlink-escape/`,结构照抄
    ATTACK-002(attack.diff 用 git 支持的模式 120000 建软链指向工作区外);
    更新 `bugs/attacks/README.md` 计数(8→9)。
- **范围**:`app/gitops/patcher.py`、`bugs/attacks/ATTACK-009-symlink-escape/`(新)、
  `bugs/attacks/README.md`、`tests/test_attacks.py`、`tests/test_gitops.py`(追加用例)。
- **测试**:ATTACK-009 被拒且 reason 正确;构造"patch 目标路径本身是工作区内软链"的
  单测 → 拒;既有 8 个攻击样例回归不变;正常 patch 应用回归不变。
- **验收**:`pytest -q tests/test_attacks.py tests/test_gitops.py` 全绿 + 全量绿。
- **commit**:`fix(gitops): apply 前软链/路径逃逸校验(ATTACK-009)`

## E3 verify 双跑一致性复核(必做,90min)

- **来源**:面试审计 P1-3——判定面与被测代码同机,threat-model §4 自认不防
  junit 伪造;P0-1 整改(期望 id 判定+控制面禁改)是补丁式,本卡加结构性抬高。
- **目标**:伪造一次绿的结果,必须同时伪造两次独立运行且二者一致,攻击成本翻倍。
- **设计决策(定死)**:
  - `Settings` 新增 `verify_double_run: bool = True`;
  - `app/graph/nodes.py` verify 节点(现 :343-356):当第一遍双测试集**全绿**
    (即即将判 resolved 的路径)时,用**相同命令再跑一遍**双测试集,比较两次 junit:
    测试 id 集合必须相等,且第一遍通过的 id 第二遍无任何失败 → 通过;
    不一致 → 任务转 `NEEDS_REVIEW`,reason=`verify_mismatch`,两次运行摘要写入轨迹;
  - 非 resolved 路径(本就失败)不多跑,开销不变;
  - 开销口径:成功路径 pytest 4→6 次,写入 `docs/design.md` §8 一行;
  - **除上述 double-run 分支外,verify 其余逻辑一行不动**;resolved 判定规则本身
    (转绿+回归绿)不改——这是"复核"不是"改判"。
- **范围**:`app/config.py`、`app/graph/nodes.py`(仅 verify 分支)、
  `docs/design.md`(§8 一行)、`tests/test_graph.py`(追加)。
- **测试**:fake 回放 resolved 路径断言 pytest 恰 6 次拉起且 FINISHED;
  monkeypatch 适配器使第二遍结果与第一遍不一致 → NEEDS_REVIEW + reason 正确;
  `verify_double_run=False` 时回归为 4 次(现有断言不受影响)。
- **验收**:`pytest -q tests/test_graph.py` 全绿 + 全量绿。
- **commit**:`feat(graph): verify 双跑一致性复核(verify_double_run,默认开)`
