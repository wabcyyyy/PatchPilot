### 1. P0/P1：判定与隔离可被击穿

- **N-1（P0）`pytest` 模块影子劫持判定**（两位审查员独立发现）：
  `python -m pytest` 把 cwd（=工作区）置于 `sys.path[0]`（`pytest_adapter.py:93` + `local_runner.py` cwd=workspace）。
  Agent 提交新增 `pytest/__init__.py`：`is_test_file` 放行（目录段 `pytest` 不是测试目录），自定义任务
  `allowed_paths=None`（`schemas.py:20-22`）路径门禁恒过。影子包读 `sys.argv` 里的 `--junitxml`，
  写一份 requested id 全 passed 的 junit 并 exit 0 —— P0-1 整改的期望 id 判定被整体架空。
  同类：`xml/`（junit 由它写出）、stdlib 同名顶层模块、被测源码 `atexit` 改写 junit。
  **整改**：gates 新增 shadow 门禁——diff 中**新增**文件的顶层段命中 `sys.stdlib_module_names ∪ {pytest,_pytest,py,pluggy,iniconfig,execnet}` 即拒；`.gitignore`/`.gitattributes` 纳入禁改（否则可把影子文件藏出 diff，见 N-6）；威胁模型补记「被测代码与判定器同进程」的剩余边界。
- **N-2（P1）`bug_id` 路径穿越绕过根白名单**：`service.py:110-128` 只对 `repo_path` 分支调
  `ensure_repo_allowed`；`load_bug`（`bugset.py:64-70`）对传入路径无任何约束。
  `POST /api/tasks {"bug_id": "D:/evil/task"}` 可加载白名单外任意目录的 manifest+repo 并执行其代码——
  T12.2 的 `PATCHPILOT_ALLOWED_REPO_ROOTS` 形同虚设。**整改**：API schema 对 bug_id 强制 `^BUG-[A-Za-z0-9_-]+$`；service 层 bug_id 分支补 root 包含校验（纵深）。
- **N-3（P1）测试 id 放行 `..`/盘符/UNC**：`bugset.py:23` 正则含 `./:-`，`../evil/tests/x.py::t`、
  `C:/x.py::t`、`//host/x.py::t` 全过校验，pytest 会以 cwd=工作区收集并**执行工作区外**代码。
  **整改**：validate_test_ids 拒绝 `..` 段、盘符前缀、`//` 开头、`/` 开头。
- **N-4（P1）SWE-bench 适配器漏接校验**：`swebench.py:99-110` 直接把 jsonl 里的
  `fail_to_pass/pass_to_pass` 塞进 BugTask，未调 `validate_test_ids`。外部数据文件恰是注入面最大的入口。
  **整改**：`to_bug_task` 补校验 + 恶意 jsonl 拒绝测试。
- **N-5（P1）BUDGET_EXCEEDED 不是转移终点**：`builder.py:33-36` 条件边只认 NEEDS_REVIEW/VERIFY_FAILED；
  localize 超预算后 `route_localize` 返回 continue → propose 照跑；propose 超预算后 `route_propose`
  返回 apply → 若补丁已在工作区且 verify 通过，`finish` 直接判 FINISHED/resolved——
  第 6 项资源门禁被「顺路」绕过，report 里 `tokens_used > token_budget`。
  **整改**：两条 route 把 BUDGET_EXCEEDED 映射到 end；补状态机测试。
- **N-6（P1）`.gitignore` 是取证盲区**：`differ.py` 的 `git add -A -N` 跳过 ignored 文件；
  Agent 改根 `.gitignore`（非测试文件、自定义任务放行）即可把任意新文件藏出 diff/changed_files/diff.patch，
  与 N-1 组合时连取证产物都是"干净"的。**整改**：`.gitignore`/`.gitattributes` 纳入禁改控制面。
- **N-7（P1）CANCELLED 与终态回写双向 TOCTOU**：`service.py:252-254`（先读后写）与 `:325-327`
  （cancel 无条件 UPDATE）互相覆盖；`repository.py:88-108` 无状态守卫。已 resolved 任务的终态可被
  并发 cancel 改写成 CANCELLED（证据链永久矛盾），或客户端收到「已取消」而任务实际跑完。
  **整改**：条件下沉为单条原子 UPDATE（`WHERE status!='CANCELLED'` / `WHERE status NOT IN (终态)`），
  按 rowcount 判定输赢；终态集合收敛为 repository 单一权威。
- **N-8（P1）local 后端向不可信仓库泄漏宿主环境变量**：`local_runner.py:90-96` 未传 `env=`，
  `PATCHPILOT_API_TOKEN`/`PATCHPILOT_LLM_API_KEY` 整包进入测试子进程；conftest `os.environ` 读出
  写进工作区文件即可外带。**整改**：最小 env 白名单（PATH/SYSTEMROOT/COMSPEC/TEMP/TMP 等）。

### 2. P2：预算口径、证据链与健壮性

- **N-9** `max_rounds` 是新假活键：`service.py:156` 只落库，`_execute` 不传引擎；`build_custom_bug`
  未收 max_rounds（两个审查员独立发现）。**整改**：构建后覆写 `bug.max_rounds`，引擎两路自然生效。
- **N-10** plain 引擎时间预算只有进循环前一次检查点（`driver.py:153-160`），循环内无时间检查；
  锁 TTL（`task_timeout+60`）可早于任务结束 → 同键并发窗口未闭合。**整改**：`run_plain_loop`
  的 turn 边界补时间检查（本轮先做 graph 侧 N-5/N-9 与 plain 侧 turns 检查，锁心跳留第 2 轮）。
- **N-11** token 预算按循环重置且失败循环的已耗 token 不入账（`plain_loop.py:65-66`、
  `nodes.py:154-159/223-228`）→ 任务级真实消耗可达配置 2-3 倍，report 系统性低估。第 2 轮处理（需要账本下沉设计）。

  `runner.py:117-118`）——与 plain 引擎（`driver.py:195-196/201`）同场景口径不一致。第 2 轮处理。

  与 `regression_denominator` 口径互相矛盾。**整改**：分子只算 `patch_applied`。
- **N-14** `pricing.py:34-35` 畸形覆盖条目抛 IndexError/KeyError 不在捕获集——炸掉 `finally` 里的
  `estimate_cost`，已 resolved 的任务丢失 report.json 被降级 NEEDS_REVIEW。**整改**：扩 except + 逐条容错。
- **N-15** 杀树后二次 `communicate()` 无超时（`local_runner.py:105`）：逃逸进程组的分离孙子进程
  持有管道写端 → 任务线程永久挂死。**整改**：二次 communicate(timeout=10) + 兜底 kill。
- **N-16** `check_patch` 以 stderr 为空判成败、忽略 rc（P2-8 未修）；真正 apply 失败抛
  `GitCmdError`（RuntimeError，不在异常分层内）与 docstring 矛盾。**整改**：rc 判定 + apply 收敛为结构化结果。
- **N-17** report.json 非原子写 + `/report` 直接 json.loads：轮询窗口撞上半截文件返回 500

- **N-18** 500 兜底把 `str(exc)` 原文外泄且不落日志（`app.py:48-58`）；协作式取消被记成

- **N-20** `recover_stale` 只修状态不清 Redis 锁：崩溃重启后同键重试被 409 卡死到 TTL≈16 分钟，
  且报错语义错误。**整改**：lifespan 恢复时同步清锁（第 2 轮，与锁心跳一并设计）。
- **N-21** 停机不传播取消：`cancel_futures=True` 不动在途任务，非 daemon 线程阻塞进程退出；

- **N-22** 自定义任务幂等键含随机段恒为新（`bugset.py:132` + `service.py:134`）：幂等/防重层对
