## 归档约定

1. 执行完的计划与对应完成报告放在本目录，保留文件名并更新链接。
2. 归档时说明已完成、部分执行、停手、替代等状态，不能将未执行任务改为完成。
3. 正文内历史任务、授权和环境描述仅解释当时过程；新任务按当前 SPEC、AGENTS.md 和当次授权执行。
4. 原始测量继续保留在 `../evidence/` 或原始 runs 目录，不为归档重算数字。
