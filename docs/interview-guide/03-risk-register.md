# 03 · 风险与表达边界

这里列当前局限，面试准备优先级与产品缺陷 P0/P1 不是同一套分级。
本轮已确认缺陷与处置见 [校准任务卡](../work-notes/realignment-2026-10-12.md)。

| 风险 | 当前事实 | 推荐回答 |
|---|---|---|
| 模型效果 | fake 回放包含参考答案；真实 SWE/消融是有限历史实验，当前升级未复跑 | 回放证明控制链，历史真实实验不能外推当前修复率 |
| 默认隔离 | local 执行目标 conftest 与复现脚本，共享宿主权限；Docker 两条路径限制不同 | 目录副本不构成沙箱，部署要单独验证 |
| 测试过拟合 | 指定测试全绿可与上游语义不等价；不受信 JUnit 仍能伪造 | resolved 是声明测试与规则下的结论，不是语义正确证明 |
| 验收身份 | 具体 node IDs/候选 hash/验证 attempt 均重要 | 恢复只恢复输入与进度，成功必须重新验证 |
| 冻结配置 | 本轮补后端/超时/初始账本/模型身份接线，旧契约缺键按兼容规则回退 | 指明哪些字段冻结，不承诺所有外部环境永不变 |
| 资源估算 | chars/4 + 协议常数，价格估计非真实账单；未知用量不能当零 | 预留与计量可审计，不宣传绝不超 provider 账单 |
| 服务并发 | 单进程线程池/SQLite线程锁/SSE轮询；没有真实负载指标 | 配置并发不是测量吞吐，未证明多实例领取安全 |
| Redis | 可选任务锁；启动连接失败回内存，运行中故障可能失败 | 不是缓存、队列或任务调度器，也不是多实例安全证明 |
| 输入与输出 | 仓库说明部分脱敏/作用域校验，测试输出没有通用秘密过滤 | 权限由平台强制，prompt 注入与输出泄漏仍有边界 |
| 仓库检索 | AST/字面/符号，无向量库或召回评测 | 不声称做了 semantic/hybrid retrieval 或量化召回 |
| 委派 | 默认关闭、有界单层，独立会话，父预算与验收独占 | 不是开放式群聊，不允许子任务覆盖成功判定 |
| 恢复依赖 | checkpointer 可降级不可恢复；旧身份不完整转待审 | 检查点存在不等于恢复可用，更不等于 exactly-once |
| AI 协作 | Git 作者或 Co-Authored-By 不能精确证明代码生成比例 | 讲自己掌握的验收、关键链路和修复证据，勿编造参与百分比 |

本轮保留 legacy_v1、旧回放与 fold_output，因为有明确契约/历史实验调用方。
reset_workspace 在 plain 全量工具表可达，graph 阶段不开放，不能称“全产品死配置”。
规范文案可以按既有实现校准，AGENTS 的保护区限制的是未经讨论的语义变化，不是禁止修正文档。
历史 PROGRESS/TODO/实验快照保留当时事实，并明确不能作为当前完成证据。
