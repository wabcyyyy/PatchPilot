# 10 · 简历表述核对

| 主张 | 当前可支持表述 | 限制 |
|---|---|---|
| Agent 平台 | 实现 Python/pytest 仓库的诊断、补丁与平台独立验收原型 | 无生产用户/可靠性承诺 |
| LangGraph | 显式阶段拓扑、条件边、检查点，阶段内共享模型工具循环 | 平台实现恢复重验，框架不自动保证正确性 |
| 验收护栏 | 非空补丁、双集身份、门禁、资源、取消合取；graph候选绑定 | 不能证明所有恶意输入都被防住或语义等价 |
| 恢复 | graph候选重应用/重验、账本与会话绑定、拒缺身份 | 不声明 exactly-once 或多实例可靠恢复 |
| Docker | 可选容器执行，pytest与诊断命令限制不同 | 默认local、socket部署边界，非生产沙箱声明 |
| 幂等/存储 | 完整契约hash幂等、SQLite事务终态、轨迹持久化、可选Redis锁 | 单进程原型，非分布式队列 |
| 上下文 | AST/字面/符号检索，有界回执/原文证据，平台观测记忆 | 无向量RAG、长期记忆或检索质量分数 |
| 评测 | 自建回放、版本化指标、历史真实SWE/消融与负结果记录 | fake含答案，样本受限，当前升级未复跑，非官方成绩 |

建议 bullet：

- 实现 PatchPilot 诊断与补丁验证原型，将模型动作限制为阶段工具集合，以平台独立 pytest/JUnit 验证与共享合取规则判定修复。
- 实现 graph 候选工件与恢复重验，持久化会话、证据和资源账本；对配置漂移、取消与已知攻击场景补回归护栏。
- 建立版本化评测与实验身份记录，区分离线答案回放、有限真实 SWE 实验和未验证局限，不宣称官方解决率。

不要写“准确率xx%”“生产级隔离”“并发提升xx倍”“官方SWE成绩”或固定当前CI通过数，除非有对应完整证据。
