# 09 · 面试表达稿

## 核心价值

“这个项目的价值是让平台判定可追溯：模型提出补丁，平台通过门禁、真实测试、
完整身份与资源账本验收，模型的 finish 不能直接写 resolved。恢复遇到写阶段重新应用候选并重验。”

## 为什么 LangGraph

“图提供阶段拓扑和 superstep 检查点，工具循环由平台手写并被两引擎复用。
模型在阶段内自主行动；平台控制阶段路由、能力边界与最终验收。
plain 单轮驱动用于替代编排与部分评测，graph 有多轮候选/交互/恢复，两者功能不等价。”

## 有效性与不足

“离线 FakeLLM 含参考答案，只证明控制链。真实 SWE/两臂消融确有历史记录，
有限样本、选择偏差、抽样回归和早期跨引擎口径限制都保留，后续还有负结果。
当前升级没有重新实跑，所以不报官方成绩，也不把历史解决率当当前版本收益。”

“默认 local 不是沙箱，SQLite 服务按单进程原型设计，费用也是价表估计而非账单。
全绿可以过拟合，平台规则不能证明语义等价或防住任意恶意仓库。”

## 本轮真实修复

“审查发现受理 TaskSpec 虽冻结配置，初始账本与 pytest 路由仍读当前全局配置。
修复为任务配置副本与显式后端/超时传递，并用 graph/plain 真实 pytest 链验证配置漂移。
Docker custom 预检原来仍会宿主 collect，现在按受理后端查 daemon，避免宿主导入 conftest。
删除两个无执行调用的遗留定义，更新文档锚点到真正的身份判定。没有放松门禁或测试期望。”

## AI Coding

如实说明 AI 协作，不用 commit/行数推断生成比例。应能现场讲清调用方、契约、失败路径与测试证据。
不能掌握的代码应明确说需要核对，不能把过度自信或固定测试数量当工程能力。
